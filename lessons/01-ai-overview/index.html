作为程序员，你正站在 AI 浪潮的第三幕开场。

套娃图必讲。三件事：① AI 是大筐；② ML 是用数据驱动的子集；③ DL 是用神经网络的更小子集；④ GenAI 是 DL 的'生成派'，特点是能产出新内容；⑤ LLM 是 GenAI 中的语言专项。让听众用两句话能给非技术家属解释清楚。

AI · ML · DL · GenAI

  • AI — 让机器有"智能"的总集（1956 起）
  • ML — 从数据里学规律（1980s）
  • DL — 用神经网络学（2012 ImageNet）
  • GenAI — 能"生成"内容的 DL（2017 Transformer 起）
  • LLM — GenAI 中专攻语言的那部分（2022 ChatGPT 引爆）
一句话引入下张：5 个节点串成一条线。
70
年五个关键节点
时间线讲故事：1956 命名 → 1986 反向传播让神经网可训 → 2012 AlexNet 把 DL 推上王座 → 2017 Transformer 改写规则 → 2022.11 ChatGPT 让全世界感受到。强调：每次跃迁都伴随算力 + 数据 + 算法三件套同步突破。

关键节点

  • 1956 · 达特茅斯会议，"AI"被命名
  • 1986 · 反向传播让神经网络可训练
  • 2012 · AlexNet 引爆深度学习
  • 2017 · Transformer 论文发表
  • 2022.11 · ChatGPT 上线，世界变了
  • 2024– · Agent / 多模态 / 推理模型
结合数据：ChatGPT 上线 2 个月用户破亿，是 TikTok 9 个月、Instagram 30 个月、Facebook 4.5 年的纪录粉碎机。这是消费互联网史上最快的拐点，没有之一。

为什么这次不一样：① 通用性 — 一个模型干无数事；② 对话化 — 自然语言就是 API；③ 涌现能力 — 量变引发质变；④ 开发者门槛骤降 — 调 API 就能做产品。前三次（互联网/移动/云）都没同时具备这四条。

为什么这次不一样

  • 通用性：一个模型，无数任务
  • 对话化：自然语言就是 API
  • 涌现能力：尺度大到一定程度就"开窍"
  • 开发者友好：人人可调用，门槛骤降
现状版图：闭源四强 + 开源四杰。可以补充国产军团：DeepSeek/Qwen/智谱/Kimi。提一句：开源闭源差距正在缩小到几个月。
