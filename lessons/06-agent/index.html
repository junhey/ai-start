四件套

Tool Use = Function Calling + 多工具并行。现代旗舰模型都能一次返回多个并行调用。

Tool Use · 工具调用

  • Function Calling：模型输出结构化函数调用
  • JSON Schema：声明工具的入参类型
  • 多工具并行：现代模型支持一次调多个
  • 工具数：建议 ≤ 20，太多会"选困难"
工具数量经验：≤ 20 是甜区。再多模型容易'选困难'，需要分层路由。

完整 Function Calling 流程：定义工具 → 发请求 → 解析 tool_calls。注意模型不会真的执行函数，你要自己调。

function calling 完整代码


from openai import OpenAI
client = OpenAI()

tools = [{"type": "function", "function": {
    "name": "get_weather",
    "description": "查询城市天气",
    "parameters": {"type": "object", "properties": {
        "city": {"type": "string"}
    }, "required": ["city"]}
}}]

resp = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "杭州天气如何？"}],
    tools=tools
)

# 解析 tool_calls
tool_call = resp.choices[0].message.tool_calls[0]
print(f"调用: {tool_call.function.name}({tool_call.function.arguments})")
Function Calling 的 Schema 写法。一定要写好 description，模型靠它决定何时调用哪个工具。

记忆系统

  • 短期：当前对话窗口（messages 数组）
  • 长期：向量化存储 + 检索（RAG 思路）
  • 结构化：用户 profile / 偏好 / 实体记忆
  • 遗忘：定期摘要、淘汰冷数据
记忆三层：短期对话窗口 / 长期向量化 / 结构化用户档案。要有'遗忘'机制，否则成本失控。

规划
能力

从"边走边想"到"先想再走"。

规划是 Agent 真正进阶的标志。Plan-and-Execute 适合明确流程；Tree of Thoughts 适合搜索；Reflection 适合可回头重做的任务。

规划方法

  • Plan-and-Execute：先列计划，再逐步执行
  • Tree of Thoughts：探索多分支，回溯最优
  • ReWOO：先规划全部步骤再执行，省 token
  • Reflection：自我反思修正
多 Agent 协作：分工 / 辩论 / 流水线 / 层级。提醒：多 Agent 不是银弹，简单任务单 Agent 就够。

多 Agent 协作

  • 角色分工：PM / Coder / Reviewer / Tester
  • 辩论：多方观点提升决策质量
  • 流水线：上一个的输出 = 下一个的输入
  • 层级：Lead Agent 调度 Sub Agent
MCP 是 Anthropic 推的工具协议标准，类比 LSP 之于编辑器。今年的趋势：写一次 MCP server，所有客户端都能用。

MCP
协议

Anthropic 推的"Agent 工具的 USB-C"。

MCP 的关键价值：解耦工具实现和 Agent。下一年估计会爆发。

MCP 是什么

  • Model Context Protocol
  • 统一 LLM 与外部工具/资源/服务的接口标准
  • 写一次 MCP server，所有支持的客户端都能用
  • 类比：LSP 之于编辑器
  • → 工具生态的基础设施
最小 MCP Server 只需 5 行核心代码。用 FastMCP 装饰器声明工具，stdio 模式启动即可被客户端发现。

最小 MCP Server


# pip install mcp
from mcp.server.fastmcp import FastMCP

mcp = FastMCP("demo")

@mcp.tool()
def add(a: int, b: int) -> int:
    """两数相加"""
    return a + b

mcp.run()  # stdio 模式启动

失败模式四件套：死循环 / 幻觉决策 / 成本失控 / 过度自信。任何 Agent 上线必须设步数+成本+超时上限。

失败模式

  • 死循环：相同的工具反复调用
  • 幻觉决策：编造工具名 / 参数
  • 成本失控：单任务 100 美刀的故事很多
  • 过度自信：不该用工具时也用
  • → 必须设：步数上限、成本上限、超时
