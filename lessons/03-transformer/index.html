self-attention


Attention(Q, K, V) = softmax( Q · K^T / √d_k ) · V

Q = X · W_Q   ← 我"想问什么"
K = X · W_K   ← 别人"能提供什么"
V = X · W_V   ← 别人"实际给什么"

三步拆解

  • ① 算相关性 · Q × K^T → 每个 token 对其他 token 的"关注度"
  • ② 缩放归一化 · ÷√d_k → softmax 得到注意力权重
  • ③ 加权求和 · × V → 得到上下文向量
  • 本质：每个 token 用所有 token 的加权信息更新自己

多头
×8 / ×16 / ×128

多个观察视角并行，再拼起来。

为什么要多头

  • 单头只能学一种"关系模式"
  • 多头 = 多个并行注意力子空间
  • 有的头看语法，有的看实体，有的看共指
  • 结果 concat → 线性变换 → 输出

位置编码

  • 问题：Attention 是无序的
  • "我打你" vs "你打我" → 注意力会一样
  • 解药：给 token 加上"位置向量"
  • 正弦位置编码（原论文）
  • RoPE 旋转位置编码（现代主流，Llama 等）
