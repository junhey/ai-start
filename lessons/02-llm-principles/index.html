为什么这件小事，能产生看起来像智能的东西？

Token 不是字、不是词，是 BPE/字节对编码切出来的子词单元。强调：英文 1 词常 1-3 token，中文 1 字常 1-2 token。所以中英文计费差异巨大。

Token 是什么

  • 不是字、不是词，是 BPE 子词单元
  • "unbelievable" → ["un", "believ", "able"]
  • 中文一个字常常 = 1-2 个 token
  • 英文一个单词常常 = 1-3 个 token
  • ⚠ 计费按 token 算，不是字数

tokenizer demo


from tiktoken import encoding_for_model
enc = encoding_for_model("gpt-4")

text = "我爱 AI"
tokens = enc.encode(text)
print(tokens)
# [37046, 102, 11, 15836]   ← 4 个 token

print([enc.decode([t]) for t in tokens])
# ['我', '爱', ' ', 'AI']

三段式训练。我喜欢用三个比喻：Pretrain = 通读图书馆 / SFT = 培训对话礼仪 / RLHF = 学得体的回答。

三段式
训练

Pretrain → SFT → RLHF/DPO

Pretrain 用了万亿 token，烧掉 99% 算力。这一阶段决定了模型的'底层世界观'。

① Pretrain · 预训练

  • 数据：互联网 + 书籍 + 代码，万亿级 token
  • 任务：预测下一个 token（最朴素）
  • 目标：把世界知识"压缩"进权重
  • 代价：算力消耗 99% 都在这里
  • 类比：让一个人通读了人类大半的书
SFT 把'续写'改造成'对话'。规模从万到百万级，质量重于数量。

② SFT · 监督微调

  • 数据：高质量 (指令, 答案) 对
  • 规模：从万到百万级
  • 目标：把"续写"改造成"对话"
  • 类比：教 ta 怎么"对话"，而不是"续写小说"
RLHF/DPO 让模型符合人类偏好。DPO 比 RLHF 简单得多，正在成为主流。

③ RLHF / DPO · 偏好对齐

  • 数据：人类对两个回答打分（好/坏）
  • RLHF · 训奖励模型 → PPO 强化学习
  • DPO · 直接偏好优化，更简单
  • 目标：有用、无害、诚实
  • 类比：让 ta 学会"得体"地回答

解药四件套：RAG / 工具调用 / 引用核对 / 推理模型。下一节专讲 Transformer 内部，再下两节讲 RAG/Agent 来对治幻觉。

幻觉为什么存在

  • 本质：LLM 永远在"概率最高的下一个词"
  • 知识截断：训练数据有日期
  • 压缩损失：参数有限，细节会丢
  • 自信错误：流畅 ≠ 正确
  • → 解药：RAG、Tool Use、引用核对
采样参数实战：抽取/分类/代码用 0；创作用 0.7-1。Top-p 比 Top-k 更平滑。frequency_penalty 解决重复啰嗦。

采样参数

  • temperature · 0 = 确定 / 1 = 创造
  • top-p · 累积概率裁切（核采样）
  • top-k · 只看前 k 个候选
  • frequency_penalty · 抑制重复
  • 代码 / 抽取场景：temperature ≈ 0；创作场景：0.7-1
